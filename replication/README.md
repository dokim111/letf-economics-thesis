# 경제학 계산의 재현 안내

## 1. 공개 범위

논문의 표 3–9, 표 10의 입력 지표, 순설정 보조 회귀와 서론의 지정 기간 수익률을 계산하는 세 Python 스크립트를 제공합니다.

**원자료 CSV 세 개는 공개 저장소에 들어 있지 않습니다.** 공개 코드는 데이터를 다운로드하지 않으며 KRX 계정·인증 정보도 포함하지 않습니다. 이용자가 자료를 별도로 확보하여 아래 파일명과 열 구조로 준비해야 합니다. 입력 자료의 취득·정제 전체를 자동화한 파이프라인은 아닙니다.

계산 결과 파일도 함께 배포하지 않습니다. 입력 자료를 갖춘 뒤 실행하면 `replication_output.txt`, `accounting_sensitivity_results.json`, `accounting_sensitivity_summary.csv`, `accounting_sensitivity_output.txt`, `intro_drawdown_output.json`이 생성됩니다.

## 2. 실행 환경과 순서

Python 3.11 이상을 사용합니다. 패키지 버전은 `requirements.txt`에 고정되어 있습니다.

저장소 루트에서 다음 순서로 실행합니다.

```bash
cd replication
python3 -m pip install -r requirements.txt
python3 replicate.py
python3 accounting_sensitivity.py
python3 verify_intro_drawdown.py
```

Windows에서 실행 파일 이름이 `python`이면 `python3` 대신 사용합니다. `verify_intro_drawdown.py`는 Python 표준 라이브러리만 사용합니다. 세 스크립트는 난수를 사용하지 않습니다.

입력은 기본적으로 **각 스크립트가 놓인 폴더**에서 읽고, 결과도 같은 폴더에 씁니다. 따라서 다른 작업 디렉터리에서 스크립트를 실행해도 원래 상대경로 구조가 유지됩니다. 기존 결과 파일이 있으면 덮어씁니다. 입력 CSV는 수정하지 않습니다.

`accounting_sensitivity.py`만 입력·출력 폴더를 바꾸는 옵션을 지원합니다.

```bash
python3 accounting_sensitivity.py --data-dir /path/to/data --output-dir /path/to/output
```

`replicate.py`와 `verify_intro_drawdown.py`에는 해당 옵션이 없으므로, 아래의 정확한 파일명으로 스크립트 폴더에 입력을 배치해야 합니다.

## 3. 입력 자료

입력 세 파일은 스크립트와 같은 `replication/` 폴더에 별도로 준비합니다.

- `krx_etf_daily_20260527_20261113.csv`
- `krx_stock_daily_20260401_20261113.csv`
- `krx_stock_futures_daily_20260527_20261113.csv`

정확한 출처·기간·필수 열·단위·상품 목록·공표 시차·표본 종료일은 [DATA_SOURCES.md](../DATA_SOURCES.md)에 정리했습니다. 파일명만 맞추는 것으로 충분하지 않으며, 원래 수집 시점의 관측값과 표본 처리도 일치해야 합니다. 특히 11월 13일의 미공표 순자산을 나중에 보완된 값으로 바꾸면 유효 표본이 달라질 수 있습니다.

## 4. 논문 표·본문과 스크립트의 대응

| 논문 위치 | 계산 코드 | 제공하는 결과 |
|---|---|---|
| 4.2절 자료 정합성 | `replicate.py`, `accounting_sensitivity.py` | 순자산/NAV 환산 좌수와 당일·다음 날 상장좌수 비교, 회계 항등식 잔차 등 |
| 표 3·4 | `replicate.py` | 기간별 순자산, 1% 변동당 조정액, 조정액과 거래대금 비율, K/V |
| 표 5 | `replicate.py` | 절대 수요 감소율, 방향 상쇄율, 상품 유형별 요약 |
| 5.2절 보조 회귀 | `replicate.py` | 순설정률과 ETF NAV 수익률의 회귀; Newey–West 5시차 표준오차 및 제외 분석 |
| 표 6 | `replicate.py` | 상승일·하락일별 기준 조정액, 순설정 수요, 상쇄율 |
| 표 7 | `replicate.py` | 지정된 세 날짜의 회계적 수요 분해 |
| 표 8 | `replicate.py` | 순설정 날짜와 수익률 대리변수 변경에 따른 비교 |
| 표 9 | `accounting_sensitivity.py` | 전체 표본, ACE 제외, 하루씩 제외, 순설정 수요 절댓값 상위 5일 제외 |
| 표 10 | `replicate.py` | 충격 승수 계산에 들어가는 평균 K/V와 관련 진단. 승수 M=1/(1−λK/V)의 완성된 표 자체는 출력하지 않음 |

`replicate.py`는 표의 수치를 텍스트로 출력합니다. 표 9는 JSON·CSV·텍스트를 함께 생성합니다. 표 1의 이론적 계수, 표 2의 상품 소개, 표 11의 정책 비교, 논문 전체 조판 및 그림 1–2 생성 스크립트는 이 저장소에 포함하지 않습니다. 따라서 전체 논문의 완성본을 자동으로 다시 만드는 패키지라고 해석하지 않습니다.

## 5. 계산·해석의 주요 규약

- 기준 조정액은 `B = β(β−1)A_(t−1)r`이며, 기본 사양의 `r`은 ETF NAV 수익률을 β로 나눈 값입니다.
- 순설정액은 `F = (A_t/NAV_t − A_(t−1)/NAV_(t−1)) × NAV_t`로 재구성하고, 이에 따른 노출 조정 수요는 `f = βF`입니다.
- 절대 수요 감소율은 `C_abs = 1 − Σ|B+f|/Σ|B|`입니다. 표 9의 증가율(%)은 `−100 × C_abs`로 표시합니다. 제외 후 표본마다 분모를 다시 계산합니다.
- ACE 제외는 상품을 제외한 뒤 날짜별 합계를 만듭니다. 날짜 제외는 이미 계산한 일별 B/f 쌍을 제외하며 이후 순자산·수익률 경로를 새로 구성하지 않습니다.
- 상위 5일은 기초주식별로 합산한 `|ΣβF|`가 큰 날짜입니다. 두 종목의 제외 날짜는 다를 수 있습니다.
- 하루씩 제외한 범위는 114개의 기술적 재계산 결과 범위이며 신뢰구간이 아닙니다.
- 회귀와 민감도 분석은 관측 경로를 고정한 기술적·회계적 계산입니다. 실제 체결량, 순설정의 구조적 반응계수, 인과적 가격효과 또는 예측 성능을 추정하는 것으로 해석하지 않습니다.

## 6. 실행 확인과 검증 범위

Python 3.12.14, NumPy 2.3.5, pandas 2.2.3 환경에서 README의 설치 명령과 세 계산 명령을 실행했습니다. 저자가 보관한 원자료 CSV 세 개를 별도 로컬 실행 폴더에 복사하여 사용했으며, 공개 저장소에는 추가하지 않았습니다. 입력 파일은 실행 전후에 바뀌지 않았습니다.

`replication_output.txt`, `accounting_sensitivity_output.txt`, `accounting_sensitivity_summary.csv`는 기존 보관 결과와 바이트 단위로 같았습니다. `accounting_sensitivity_results.json`과 `intro_drawdown_output.json`의 계산값도 일치했습니다. 서론 수익률 JSON의 자료 출처 설명은 공개용 코드에서 원자료를 별도 확보하도록 바뀐 문구이므로, 이 설명 문자열을 제외하고 대조했습니다.

| 절대 조정액 증가율(%) | 삼성전자 | SK하이닉스 |
|---|---:|---:|
| 전체 표본 114거래일 | 12.65 | 19.53 |
| ACE 상품 제외 | 12.43 | 19.41 |
| 순설정 수요 절댓값 상위 5일 제외 | 7.49 | 9.66 |
| 11월 9거래일만 사용 | -1.10 | -1.42 |

이 검증은 원래 보관 자료에 대한 계산 재실행입니다. 원자료 취득·정제를 새로 수행한 검증이나 완성 논문·그림의 자동 생성 검증은 아닙니다. 특히 표 10은 K/V 입력 지표를 대조한 범위이며 충격 승수 완성표를 생성하는 코드는 포함하지 않습니다.

계산식, 추정 방법, 표본 선택 로직과 패키지 버전은 바꾸지 않았습니다. 코드 주석과 출력에 남은 초고 번호는 계산을 작성한 이력이며, 저장소 버전은 루트의 VERSION을 따릅니다.
